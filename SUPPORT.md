# Support

For non-security problems use the GitHub bug template with a minimal synthetic localhost reproduction. Include version, OS, terminal, expected behavior, and sanitized output. Do not upload real traffic or credentials. Read SECURITY.md for suspected vulnerabilities.

Maintenance is best effort, without a response or availability SLA. No enterprise support, model-provider troubleshooting, root-cause guarantees, or production traffic analysis is offered. Linux is locally tested; macOS awaits hosted CI; Windows is untested. Requests outside the SSE MVP may be deferred.
